DESHAN HERATH — RESPONSIVE PORTFOLIO STARTER
==============================================

Included:
- Responsive one-page portfolio (mobile, tablet and desktop)
- Black / white / gold theme
- About, skills, portfolio, certificates and contact sections
- Mobile navigation menu
- Placeholder certificate links

FILES
- index.html: page content and placeholders
- styles.css: responsive design
- script.js: mobile navigation and current year
- documents/: place public certificate PDFs here

IMPORTANT LIMITATIONS
This is a front-end starter. It is NOT yet connected to Google Drive.
It does NOT include an Admin Dashboard, login, database, upload backend, or secure private-document storage.
Do not upload ID cards, passports, financial records, or other sensitive documents into this public website folder.
Certificate links are placeholders and will not open until you add files with matching names or update the links.

TO EDIT
1. Open index.html in a text editor.
2. Replace placeholder text and project names with your own.
3. For certificates, put public PDF files inside documents/ and update the href paths.
4. To add a portrait, a photo section can be added later; the current design uses a graphic monogram.

HOSTING
You can publish the static front-end using a static website host, but a real Google Drive connection requires OAuth configuration and a secure backend/serverless function. Never put Google OAuth client secrets, refresh tokens, or service credentials in browser JavaScript.
Google Drive API official docs:
https://developers.google.com/workspace/drive/api/guides/about-sdk
https://developers.google.com/workspace/drive/api/guides/manage-uploads
